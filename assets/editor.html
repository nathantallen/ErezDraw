Changes apply immediately. Use the Text tool or double-click an atom to edit individual labels.

Drawing guide

Choose a tool on the left, then draw on the page. Carbon atoms are implicit at bond ends. Choose an element and click an atom to replace its label.

Bond toolClick to add a 40 px bond; click an endpoint to extend. Drag to set direction. Angles snap to 15°; hold Alt to release both angle and length constraints.
Double / triple / wedge / dashed / coordinationDraw new bonds, or click an existing bond to change its style. Clicking a single bond with the single tool cycles its order.
Ring templateClick empty space to place a ring, or an atom to attach at that vertex; click a bond to fuse a ring. Drag to orient the first bond.
Select · V / EscDraw a marquee or lasso, or click an atom/bond. Shift toggles selection. Alt swaps marquee/lasso. Drag selected atoms to move; double-click an atom or bond with a selection tool to select its connected molecule.
Rotate selectionUse Marquee or Lasso, then drag the handle at the upper-right corner. Double-click the handle or choose Object → Rotate for an exact angle. Atom labels stay upright.
Labels · LClick an atom with the Text tool, or double-click with a bond tool, to edit. Type C, N, O, S, P, F, H, I or B while one atom is selected. Arbitrary labels such as Y, La and HMDS are allowed.
Arrow / textDrag to draw a reaction arrow; click to add editable text. Select and drag to move.
Undo / redoCtrl+Z / Ctrl+Shift+Z (or Ctrl+Y). On Mac, use Command.
Copy / pasteCtrl+C / Ctrl+V duplicates within this editor. The clipboard is internal to this tab.
Delete · EDelete removes selection. E activates the eraser. Erasing a label retains bonds; erasing a multiple bond reduces its order.
Save / openEditable .chemjson drawings. MOL V2000 imports and exports molecular connectivity and coordinates.

SVG and PNG export all visible drawing content. MOL excludes arrows/text and converts coordination bonds to single bonds; use .chemjson to preserve all details. MOL import supports V2000, not V3000. For SDF, only the first record is read.

ErezDraw 0.4

An independent, lightweight 2D chemical drawing prototype with a compact 2004-era Macintosh desktop layout. It is not affiliated with ChemDraw or its publisher.

Runs entirely in your browser without network requests. Drawings are autosaved to this browser when local storage is available. Save a .chemjson file for a durable, transferable copy.

This version supports drawing and file exchange. The native application supports chemistry checks and 2D cleanup. SMILES, formula/molecular weight and full stereochemical interpretation are not implemented.
